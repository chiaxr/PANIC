Before You Begin

The Expert has the manual. The Defuser has the bomb. Only the Defuser may touch it; only the Expert may read this. Talk to each other.

Each bomb carries a number of modules. Disarm every module before the timer reaches zero. Three strikes and the bomb detonates. Many modules depend on bomb-wide information printed on the casing — ask the Defuser to read it out.

Bomb-Wide Information (Widgets)

These panels appear around the casing. They are not modules — you cannot interact with them — but modules refer to them.

Serial Number

A six-character code (letters and digits). The most-referenced fact is whether its last digit is odd. If the serial's last digit is 1, 3, 5, 7, or 9 it is odd; if 0, 2, 4, 6, or 8 it is even.

Batteries

Count the battery cells shown on the batteries panel.

Indicators

Labelled lights such as CAR, FRK, SND. An indicator is lit if its LED glows green, otherwise unlit.

Module — Wires

A panel of 3 to 6 coloured wires. Exactly one must be cut. Cutting the wrong wire earns a strike; the correct wire disarms the module.

Wire colours: Red Blue Yellow White Black

Count the wires first, then follow the matching list. "Last wire" means the one nearest the bottom. Wire order is counted top to bottom.

3 wires

  1. If there are no red wires, cut the second wire.
  2. Otherwise, if the last wire is white, cut the last wire.
  3. Otherwise, if there is more than one blue wire, cut the last blue wire.
  4. Otherwise, cut the last wire.

4 wires

  1. If there is more than one red wire and the last digit of the serial number is odd, cut the last red wire.
  2. Otherwise, if the last wire is yellow and there are no red wires, cut the first wire.
  3. Otherwise, if there is exactly one blue wire, cut the first wire.
  4. Otherwise, if there is more than one yellow wire, cut the last wire.
  5. Otherwise, cut the second wire.

5 wires

  1. If the last wire is black and the last digit of the serial number is odd, cut the fourth wire.
  2. Otherwise, if there is exactly one red wire and more than one yellow wire, cut the first wire.
  3. Otherwise, if there are no black wires, cut the second wire.
  4. Otherwise, cut the first wire.

6 wires

  1. If there are no yellow wires and the last digit of the serial number is odd, cut the third wire.
  2. Otherwise, if there is exactly one yellow wire and more than one white wire, cut the fourth wire.
  3. Otherwise, if there are no red wires, cut the last wire.
  4. Otherwise, cut the fourth wire.

Module — The Button

One big coloured button with a word on it. Ask the Defuser for both the colour of the button and the word on it.

Work down the list and stop at the first rule that applies. Ignore every rule below it.
  1. If the button is blue and says ABORT, hold the button and read the strip.
  2. Otherwise, if there is more than 1 battery and the button says DETONATE, tap the button and release it immediately.
  3. Otherwise, if the button is white and there is a lit indicator reading CAR, hold the button and read the strip.
  4. Otherwise, if there are more than 2 batteries and there is a lit indicator reading FRK, tap the button and release it immediately.
  5. Otherwise, if the button is yellow, hold the button and read the strip.
  6. Otherwise, if the button is red and says HOLD, tap the button and release it immediately.
  7. Otherwise, hold the button and read the strip.

Releasing a held button

Holding the button lights a coloured strip beside it. Ask the Defuser for the strip colour, then tell them to release the button when the countdown timer has the matching digit in any position.

Module — Keypads

Four symbols on four keys. Exactly one column below contains all four. Press the four keys in the order they appear in that column, top to bottom.

Only one column can contain all four symbols. Read the symbols to the Expert, find the column, then press in column order — not the order they sit on the keypad. A wrong key is a strike and restarts the sequence.

Module — Memory

A big display over four numbered buttons, across five stages. Write down what is pressed at every stage — later stages refer back to earlier ones.

Position means which button, counting from the left (1 to 4). Label means the number printed on the button. Record both for every stage. A wrong press is a strike and sends the module back to stage 1 with fresh numbers.
