Before You Begin

The Expert has the manual. The Defuser has the bomb. Only the Defuser may touch it; only the Expert may read this. Talk to each other.

Each bomb carries a number of modules. Disarm every module before the timer reaches zero. Three strikes and the bomb detonates. Many modules depend on bomb-wide information printed on the casing — ask the Defuser to read it out.

Bomb-Wide Information (Widgets)

These panels appear around the casing. They are not modules — you cannot interact with them — but modules refer to them.

Serial Number

A six-character code (letters and digits). The most-referenced fact is whether its last digit is odd. If the serial's last digit is 1, 3, 5, 7, or 9 it is odd; if 0, 2, 4, 6, or 8 it is even.

Batteries

Count the cells sitting in the battery tray recessed into the top edge of the casing. The tray has four wells; any of them may be empty, so a bomb can carry anywhere from no batteries to four.

Indicators

Labelled lights such as CAR, FRK, SND. An indicator is lit if its LED glows green, otherwise unlit.

Module — Wires

A panel of 3 to 6 coloured wires. Exactly one must be cut. Cutting the wrong wire earns a strike; the correct wire disarms the module.

Wire colours: Red Blue Yellow White Black

Count the wires first, then follow the matching list. "Last wire" means the one nearest the bottom. Wire order is counted top to bottom.

3 wires

  1. If there are no red wires, cut the second wire.
  2. Otherwise, if the last wire is white, cut the last wire.
  3. Otherwise, if there is more than one blue wire, cut the last blue wire.
  4. Otherwise, cut the last wire.

4 wires

  1. If there is more than one red wire and the last digit of the serial number is odd, cut the last red wire.
  2. Otherwise, if the last wire is yellow and there are no red wires, cut the first wire.
  3. Otherwise, if there is exactly one blue wire, cut the first wire.
  4. Otherwise, if there is more than one yellow wire, cut the last wire.
  5. Otherwise, cut the second wire.

5 wires

  1. If the last wire is black and the last digit of the serial number is odd, cut the fourth wire.
  2. Otherwise, if there is exactly one red wire and more than one yellow wire, cut the first wire.
  3. Otherwise, if there are no black wires, cut the second wire.
  4. Otherwise, cut the first wire.

6 wires

  1. If there are no yellow wires and the last digit of the serial number is odd, cut the third wire.
  2. Otherwise, if there is exactly one yellow wire and more than one white wire, cut the fourth wire.
  3. Otherwise, if there are no red wires, cut the last wire.
  4. Otherwise, cut the fourth wire.

Module — The Button

One big coloured button with a word on it. Ask the Defuser for both the colour of the button and the word on it.

Work down the list and stop at the first rule that applies. Ignore every rule below it.
  1. If the button is blue and says ABORT, hold the button and read the strip.
  2. Otherwise, if there is more than 1 battery and the button says DETONATE, tap the button and release it immediately.
  3. Otherwise, if the button is white and there is a lit indicator reading CAR, hold the button and read the strip.
  4. Otherwise, if there are more than 2 batteries and there is a lit indicator reading FRK, tap the button and release it immediately.
  5. Otherwise, if the button is yellow, hold the button and read the strip.
  6. Otherwise, if the button is red and says HOLD, tap the button and release it immediately.
  7. Otherwise, hold the button and read the strip.

Releasing a held button

Holding the button lights a coloured strip beside it. Ask the Defuser for the strip colour, then tell them to release the button when the countdown timer has the matching digit in any position.

Module — Morse Code

A light blinks one word in Morse. Decode it, look up its frequency, tune the dial with the arrows and press TX.

The light repeats forever with a long gap between repeats — that gap marks the start of the word. Every word begins with a different letter, so the first letter alone identifies it.

Module — Wire Sequences

Four panels of up to three wires, shown one panel at a time. Each wire runs to terminal A, B or C — it may run straight across or slope, so read the letter at the end it arrives at, not the one it leaves from.

Keep a running count of each colour across the whole module, not just the current panel — the third red wire you have seen is occurrence 3 even if it is the first one on this panel. Cut a wire only if its terminal appears in that occurrence's row. Press the down arrow to move on; doing that with an uncut wire that needed cutting is a strike.

Module — Mazes

A 6×6 grid with invisible walls. Two circles mark which maze is in play; the white square is the defuser, the red triangle is the goal.

Ask where the two circles are and find the matching maze below — no two mazes share the same pair. Then read out moves one at a time. Walking into a wall is a strike, so check every step before calling it.

Module — Fold-Out

Six squares on a 4×4 lattice, columns numbered 1–4 and rows lettered A–D. The six squares always fold into a cube.

Take the grid one row at a time — "row B: nothing, star, circle, nothing" — and write it down before you start folding. The symbols are always circle, triangle, square, star, cross and crescent, one of each, so every square has a name. Exactly one square is drawn with a heavy ring round it: the anchor.

Folding the net

Work out which squares end up on opposite faces of the cube. Three rules settle every net this module can show.

  1. Any three squares in a straight line: the two on the ends are opposite faces.
  2. Along a run that turns at every step, the two squares three steps apart are opposite faces.
  3. Once two pairs are known, the two squares left over are the third pair.

In the worked example the filled squares are A2 B1 B2 B3 B4 C2. Rule (a) applied three times gives every pair: B1–B3, B2–B4 and A2–C2.

Which square to press

Take the first row that applies, then press the square opposite the one it names.

Module — Tape Reader

A strip of instruction cells, a register showing the starting value, and a keypad. Execute the tape by hand and type the result.

Ask for the batteries, indicators and serial first. Three of the instructions read the casing — and so does the reading direction below — so you cannot start without them. Then ask for the starting value in the register, then the glyphs in order.
Reading direction. If the serial number contains a vowel (A E I O U), read the tape backwards — start from the end away from the triangular marker. Otherwise read it forwards from the marker. Check this before the first instruction, not after.

Module — Pipeworks

A 4×4 grid of pipe tiles, an inlet on the left, three outlets X, Y and Z on the right, a lettered rule plate and a valve. Tapping a tile turns it; only the valve commits.

Turning tiles is free — no strike, no limit — so build the whole route out loud before touching the valve. A tile with a rivet on it will not turn; that is information, not a trap. A tile with a red cross is a burst seal.

Naming a tile

Every tile is named by the edges it joins, clockwise from north: N, E, S, W. So "C2 is an elbow, SW" is complete and unambiguous.

Which outlet

Add the number of batteries to the number of lit indicators, and take the remainder on division by three: 0 is X, 1 is Y, 2 is Z. The outlets are lettered downwards.

The rules

Flow starts at the inlet and spreads through every pair of tiles whose facing edges are both open. A commit passes only when all of these hold.

  1. The flow reaches the target outlet.
  2. The flow reaches no burst seal. This one always applies.
  3. The rule on the plate holds.
PlateThe flow must…
Apass through exactly one tee
Bpass through exactly two tees
Center the outlet from the tile directly above it
Dpass through every rivetted tile

Any route that satisfies all three is accepted, not just the one the module had in mind. A failed commit is a strike and leaves the grid exactly as it is, so adjust rather than start over.

Module — Star Chart

A constellation on a lettered field. Stars come in three brightnesses: bright (large, with a wide halo), medium (smaller, faint halo) and dim (small and grey, no halo).

The chart is rotated, by any angle. The grid letters are for pointing at a star — never for identifying the constellation. Never ask "which star is at the top"; ask about counts and distances.
Do this first, before anything else: discard any dim star that has nothing else near it — nothing within about one grid square. Those are field stars, not part of the constellation, and every rule below ignores them. A lone bright star is never discarded; on one constellation it is the whole point.

Identifying it

Count the stars that are left, then count how many of those are bright. Every pair of counts is shared by two constellations, so counting narrows the chart to a pair and no further: the description is what tells the two apart. Like the counts, it only ever talks about neighbours and distances, so the rotation cannot spoil it.

Module — Colour Match

A key word, a colour wheel and a SUBMIT button. The table below gives the colour that key stands for — but it does not name it. Describing it is your job.

Ask the Defuser for the key word and the battery count. Find the key's row, read the patch in the column its battery count picks, and describe that colour. The Defuser drags the crosshair on the wheel — hue around, washed-out at the middle to vivid at the rim — watches the PICKED swatch, and presses SUBMIT. Two keys in a row disarms the module.
You do not have to be exact. The module accepts any pick that is closer to this patch than to any other patch in the table — about a sixth of the wheel's radius in every direction.
A wrong colour is a strike, and both keys are re-drawn — you will have to look the module up again from the start, so describe carefully rather than guessing.
Colour blindness. Most of this palette survives it — the colours differ in lightness as well as hue, which is what a colour-blind viewer reads them by. Two pairs are the exception: the mid greens are hard to separate under tritanopia.

Needy Module — Venting Gas

Wakes up now and then, asks a question, and gives the defuser a limited time to answer with Y or N.

Needy modules are never disarmed — they keep coming back for the whole round and are not counted in the module total. Ignoring one is a strike.

Needy Module — Capacitor Discharge

A capacitor that charges the whole time the bomb is live. The meter climbs on its own; holding the lever drains it.

Tell the Defuser to check this one every so often and hold the lever until the meter is low. Letting the meter fill completely is a strike, and it starts charging again immediately.

The meter turns red near the top as a warning. Holding needs only one finger and nothing else on the module, so it is safe to do while thinking about another one.

Needy Module — Knobs

Twelve lights and a knob with four positions. Unlike the other needy modules there is nothing to answer: the knob simply has to be pointing the right way when the countdown ends.

Read the lights out as two rows of six, left to right, saying which are lit. Find the matching pattern and tell the Defuser which way to point the knob. Tapping the knob turns it one quarter clockwise, so it may take several taps.
